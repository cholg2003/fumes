### Option 1: Direct Download (Easiest)

1. **Download the HTML file:**
   - File location: `/app/Medical_Insurance_System_Presentation.html`
   - Right-click the file in your file browser
   - Select "Download"

2. **Open in Browser:**
   - Open the downloaded HTML file in any web browser (Chrome, Firefox, Edge, Safari)

3. **Save as PDF:**
   - Press `Ctrl+P` (Windows/Linux) or `Cmd+P` (Mac)
   - Select "Save as PDF" as the destination
   - Click "Save"
   - ✅ Done! You now have a PDF file

   - Scale: 100%

2. **Print Settings:**
   - ✅ Include background graphics

   - ✅ Color mode: Color (not grayscale)
