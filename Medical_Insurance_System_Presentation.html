🎯 System Overview

What is this system?

A Medical Insurance Claims Management System that digitally tracks and manages the entire lifecycle of medical claims from service provision to payment settlement.

Key Stakeholders

🏢 Insurance Companies

  • Provide coverage to families
  • Make deposits to hospitals
  • Settle outstanding claims

🏥 Hospitals

  • Provide medical services
  • Submit claims for services
  • Receive payments from insurance

👨‍👩‍👧‍👦 Families/Patients

  • Have insurance coverage with allotted amount
  • Receive medical services from hospitals
  • Their balance is tracked for each claim

Core Features

  • Patient & Family Management: Track families and their members with allotted balances
  • Claims Processing: Submit, track, and settle medical claims
  • Financial Tracking: Monitor deposits, payments, and outstanding balances
  • Multi-Hospital Support: Manage multiple hospitals in one system
  • Role-Based Access: Different permissions for different user types
  • Real-Time Dashboard: Visual overview of financial status and claims

👥 User Roles & Permissions

1. 👑 Superadmin (Insurance Company)

Highest level access - Full system control

  • Create and manage all hospitals
  • Add deposits to hospital accounts (insurance payments)
  • Mark pending claims as paid
  • Void/cancel claims when needed
  • View all claims across all hospitals
  • Suspend/unsuspend families or members
  • Access to complete admin panel

2. 🏥 Hospital Admin

Claims operations for their hospital

  • Search and view patients
  • Submit medical claims
  • Edit existing claims
  • View their hospital's financial status
  • Print claim receipts
  • Cannot create/edit families, members, or price lists
  • Cannot mark claims as paid or void them

Note: All master data management (families, members, price lists) is restricted to Superadmin only.

3. 💰 Finance Staff

Financial operations and reporting

  • View claims and financial reports
  • Submit claims for patients
  • Print claim receipts
  • Search for patients
  • Cannot edit master data (families, members, price lists)

4. 📋 Reception Staff

Front-desk operations - Limited access

  • Search for patients
  • Submit claims for walk-in patients
  • View patient balances
  • Cannot view financial reports
  • Cannot edit any master data

⚙️ Special Actions & Features

1. Void Claim (Superadmin Only)

When to use: Claim needs to be cancelled (wrong patient, incorrect services, etc.)

Process:

  1. Find claim in claims list
  2. Click red 🚫 void button
  3. Confirm: "Are you sure you want to void this claim?"

System Actions:

  • ✅ Refund family: Add claim amount back to family balance
  • ✅ Change status: PENDING → VOIDED
  • ✅ Hospital gets nothing for this claim
  • ✅ Update outstanding balance
Example:
Void CLAIM-ABC123 ($325)
Family balance: $4,675 → $5,000 (refunded)
Claim status: VOIDED

2. Edit Claim (Superadmin Only via Admin Panel)

When to use: Need to correct claim details or change claim status

Who can edit: Superadmin only (Hospital Admin cannot edit claims via Admin Panel)

Process:

  1. Go to Admin Panel → Claims tab
  2. Find claim and click edit button
  3. Change patient, services, quantities, OR STATUS
  4. Submit changes

System Actions:

  • ✅ Refund original family (if needed)
  • ✅ Charge new family (if patient changed)
  • ✅ Recalculate total amount
  • ✅ Adjust balances based on status change
  • ✅ Validate sufficient balance
  • ✅ Update claim details
NEW: Status Editing Feature

Superadmin can now change claim status when editing:

  • PENDING → PAID: Deduct from hospital deposit
  • PENDING → VOIDED: Refund family balance
  • PAID → PENDING: Refund hospital deposit
  • PAID → VOIDED: Refund both family and hospital
  • VOIDED → PENDING: Charge family balance
  • VOIDED → PAID: Charge both family and hospital

All balance adjustments are automatic!

3. Suspend Family/Member (Superadmin Only)

When to use: Family stops paying insurance premiums or policy expires

Effects of Suspension:

  • ❌ Hidden from patient search (except for superadmin)
  • ❌ Cannot create new claims
  • ✅ Existing claims remain intact
  • ✅ Data preserved for future reactivation
  • ✅ Can be unsuspended at any time

4. Bulk Family Upload (Superadmin Only)

Feature: Upload hundreds of families at once via CSV file

Who can use: Superadmin only

Process:

  1. Go to Admin Panel
  2. Click "Add Family (Bulk)" button
  3. Download CSV template
  4. Fill in family data
  5. Upload file
  6. System validates and imports all families

Benefits:

  • Save hours of manual data entry
  • Import from existing Excel/database
  • Automatic validation of all data
  • Detailed error reporting

Access Control: Only Superadmin can bulk upload families to maintain data integrity and control.

  1. Reverses old status effects (refunds if needed)
  2. Validates family and hospital balances
  3. Applies new status effects (charges if needed)

📊 Claim Status Reference Guide

Status Badges & Meanings

PENDING

Color: Yellow badge with amber/orange text

Meaning: Service has been provided to patient, waiting for insurance payment to hospital

Financial Impact:

  • ✅ Family balance already deducted
  • ⏳ Hospital waiting for payment
  • 📊 Appears in "Outstanding Claims"
  • ❌ Insurance owes hospital this amount

Available Actions:

  • 🖨️ Print receipt
  • ✅ Mark as Paid (superadmin only)
  • 🚫 Void (superadmin only)

PAID

Color: Green badge with dark green text

Meaning: Insurance has paid the hospital for this claim - transaction complete

Financial Impact:

  • ✅ Family balance deducted (done at claim creation)
  • ✅ Hospital deposit balance deducted (claim amount)
  • ✅ Outstanding balance cleared
  • ✅ Transaction fully settled

Available Actions:

  • 🖨️ Print receipt
  • ❌ Cannot be modified or voided

VOIDED

Color: Red badge with dark red text

Meaning: Claim has been cancelled/rejected - no payment will be made

Financial Impact:

  • ✅ Family balance refunded (amount added back)
  • ❌ Hospital receives nothing
  • ❌ Not counted in outstanding claims
  • 📝 Kept for historical records

Available Actions:

  • 🖨️ Print receipt (for records)
  • ❌ Cannot be reactivated

Common Reasons for Voiding:

  • Wrong patient selected
  • Incorrect services/amounts
  • Duplicate claim
  • Service not actually provided
  • Insurance denial

Status Transition Flow

NEW CLAIM SUBMITTED
        ↓
    [PENDING] ⏳
        ↓
        ├── Superadmin marks as paid → [PAID] ✅
        │                                  ↓
        │                           (End State - Complete)
        │
        └── Superadmin voids → [VOIDED] ❌
                                   ↓
                            (End State - Cancelled)

Important Notes

  • All claims start as PENDING
  • Only PENDING claims can be marked as paid or voided
  • PAID and VOIDED are permanent end states

💱 Universal Multi-Currency System

Overview

The system features a universal multi-currency architecture that allows hospitals in any country to operate entirely in their local currency. The system automatically handles currency conversion, balance management, and cross-hospital accounting through a USD-based backend.

Currency Management

  • 📊 Dynamic Currency CRUD: Superadmin can create, edit, and delete any currency
  • 💵 Base Currency: USD is the universal accounting base (cannot be deleted)
  • 🔄 Exchange Rates: All rates defined as "X local = 1 USD" (e.g., 150 KSH = 1 USD)
  • 🔢 Decimal Places: Configurable precision per currency (0-4 places)
  • 🌍 Universal Support: Works with ANY currency - tested with 6 currencies
  • ✨ Auto-Formatting: Space between symbol and amount + thousand separators

Hospital Currency Assignment

  • Each hospital is assigned a specific currency
  • All financial data (claims, balances, price lists) stored in hospital's local currency
  • Currency displayed as badges throughout the system
  • Existing hospitals default to USD

Currency Display

Action USD (Backend) KSH (Display)
